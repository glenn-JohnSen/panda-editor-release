# panda 编辑器

基于 [Sakura Editor v2.4.3](https://github.com/sakura-editor/sakura) 的简体中文版 Windows 文本编辑器（个人版）。

## 简介

- **开箱即简体中文**：全部菜单、对话框、设置页内置简体中文，无需语言包
- **编码支持**：UTF-8 / UTF-16 / GBK / Shift_JIS 等互转，打开保存不乱码
- **编辑增强**：正则搜索替换（bregonig 引擎）、Grep、标签页、拆分窗口、列框选
- **语法高亮**：C/C++、Python、Markdown 等数十种类型
- **其他**：按键宏、插件接口、ctags 标签跳转、自动备份

## 下载与安装

1. 进入 [Releases](https://github.com/glenn-JohnSen/panda-editor-release/releases) 页
2. 下载 `panda_setup2-0-0-3-x86.exe`
3. 双击运行，按向导完成安装（Win32 版，Win10 / Win11 均可）

> 安装包未做数字签名。首次运行如弹出 Windows SmartScreen 蓝色提示，
> 点击 **「更多信息」→「仍要运行」** 即可。
